CONFIGURATION

Settings & setup

Connect Termii securely through your hosting provider.

01

Open your Termii account

Find your API key and account base URL in the Termii dashboard.

Open Termii Dashboard ↗
02

Add private server environment variables

Set ADMIN_PASSWORD, TERMII_API_KEY, TERMII_BASE_URL and your approved sender ID.

ADMIN_PASSWORD
TERMII_API_KEY
TERMII_BASE_URL
TERMII_SENDER_ID
TERMII_CHANNEL
03

Configure delivery reports

In your Termii developer console, set the delivery-report webhook URL to:

https://YOUR-DOMAIN/webhooks/termii/status

Use HTTP POST with JSON. Configure the webhook signing secret before enabling signature validation.

04

Deploy the app

Deploy the sms folder as a Node.js service. Build command: npm install. Start command: npm start.

🔒 Never share your Termii API key. Store it only in your host's private environment settings, never in GitHub or browser code.
